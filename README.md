# 🏪 VyaparBot
A bilingual AI chatbot for small Indian businesses — supports Hindi, English, and Hinglish out of the box.
Built for local shops like kirana stores, coaching centres, and medical shops, VyaparBot handles customer queries 24/7 with multi-turn memory so conversations stay contextual. Powered by Groq's LLaMA-3 70B for fast, free inference and LangChain for conversation management.

## ✨ Features
* 🗣️ Auto-detects Hindi / English / Hinglish
* 🧠 Remembers full conversation history
* 🏪 3 pluggable business personas (easily extendable)
* ⚡ Free & fast via Groq API
* 🚀 One-click deploy on HuggingFace Spaces

## 🛠️ Tech Stack
Python · Streamlit · LangChain · Groq LLaMA-3 70B · HuggingFace Spaces
